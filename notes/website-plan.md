# Website plan

Drafted 2026-11-16. The theme's home on the web, in the spirit of
draculatheme.com.

## Goals

1. Let someone find their app and install the theme in under a minute.
2. Show the palette and both variants, with hex values that are easy to copy.
3. Tell the story: Ilé-Ọ̀yọ́, home of Ọ̀yọ́, and the aṣọ-òkè it is woven from.

## Audience

Developers choosing an editor or terminal theme, and people who come for the
Yoruba design story.

## Pages

| Page | Contents |
| ---- | -------- |
| Home | Name and meaning, a code sample switching between Alẹ́ and Ọ̀sán, the supported apps, one install call to action |
| Apps | A card per app; each links to its install page |
| App install page | Steps from that target's README, download links to the release files, screenshot |
| Palette | Every color in both variants with hex, contrast ratio and its aṣọ-òkè source; click to copy |
| Story | Ọ̀yọ́, aṣọ-òkè (ẹtù, sányán, àlàárì), why the variant names, pronunciation |
| Spec | Contrast rules, syntax roles, how to contribute a new app |

## Content comes from the repository

- Colors and contrast ratios: `palette/ile-oyo.json` via `scripts/lib/palette.mjs`.
- App list and install steps: `themes/*/README.md`.
- Downloads: GitHub release assets for the tagged version.
- So a palette change updates the site with no copy-pasting, like every other
  target.

## Design direction

- The site itself uses the theme: Ọ̀sán in light mode, Alẹ́ in dark, with a
  toggle; built on `themes/css/ile-oyo.css`.
- The woven-strip motif from the preview page as the visual signature.
- A typeface with good Yoruba diacritic support (tone marks over dotted
  letters: Ọ̀, ẹ́, ṣ). The system font placed them poorly in the CSS demo;
  candidates are Noto Sans / Noto Serif or Source Serif 4 for headings.
- Every page meets the same 4.5:1 rule as the theme.

## Stack options

| Option | Pros | Cons |
| ------ | ---- | ---- |
| **A. Static site generator (Astro) in `site/`** | Reads the palette and READMEs at build time; plain HTML output; easy to host anywhere | One new dependency set |
| B. Plain HTML generated by our build | No new dependencies; same pipeline as the themes | More hand-written templating as pages grow |
| C. Section of ayoola.io (Next.js) | Reuses the existing site and hosting | Ties the theme to the personal site; palette would be copied across repos |

Recommendation: **A**, deployed to Vercel (already used for ayoola.io) or
GitHub Pages.

## Milestones

1. Home, Apps, install pages for the three v0.1 targets, Palette.
2. Story and Spec pages; screenshots per app.
3. Add pages automatically as v0.2 targets land.
